# Cyclops circular display support

Keep the existing Go/WinUSB application and Display Studio. Add the Raijintek
Cyclops as a separate device kind, using only the identifiers and frame protocol
found in its official software and the connected hardware. Do not reuse the
JONSBO protocol based on screen size. Do not install drivers or change firmware.

1. Inspect the official RJK CYCLOPS 1.3.6 software and enumerate connected USB
   devices. Document the frame protocol and its evidence; distinguish source
   inspection from physical confirmation.
2. Test and implement 240 x 240 layouts, a circular mask, radial gauge and centered
   readout widgets. Author CPU temperature, GPU temperature, CPU/GPU, memory and
   activity presets specifically for the visible circle. Use existing bitmap
   typography and restrained cyan, amber and violet accents on dark backgrounds.
3. Integrate the new format into saved layouts, assignment validation, editor
   themes, previews, dragging, and device names. Preserve existing rectangular
   layouts and bindings. Offer offline circular design before hardware connects.
4. Test and implement the verified transport and device detection. Unknown
   devices must remain excluded. Test cancellation, short writes and malformed
   replies. Build the Windows application and exercise an actual frame transfer
   when the cooler is connected; report any remaining physical validation gap.
5. Run the Go and editor test suites, vet and build. Inspect rendered circular
   presets and document how to use the new display.
