# Jonsbo Resurrection v0.3.0

First public Windows amd64 release for the JONSBO TF3-360SC.

## Download and run

Download `JonsboResurrection-0.3.0-windows-amd64.zip`, extract the entire archive to a permanent folder, and run `JonsboResurrection.exe`. Right-click the neon signature icon in the Windows notification area to control monitoring and startup. The archive includes a separate console CLI under `bin/` and a SHA-256 checksum is attached to this release.

## Included

- Native Windows tray application with the maintainer's wheelcap-project signature icon.
- Reversible per-user launch at sign-in, plus optional elevated startup for CPU temperature.
- Hardware dashboards for the pump and three fan displays: CPU usage/temperature, RAM, AMD GPU usage/temperature and VRAM used/total.
- Modular Go runtime, authenticated local HTTP API, PNG previews, events and live display assignments.
- Runnable example animation/chart module and external event producer for future integrations.
- Contributor documentation, automated tests and tag-triggered versioned release builds.

## Requirements and limits

Windows amd64; hardware verified on one TF3-360SC installation. Close the original JONSBO app before controlling displays. Ryzen CPU temperature requires a separately installed signed PawnIO driver and administrator privileges; no driver is silently installed. Other unsupported measurements remain unavailable. The full-frame transport is designed for dashboards, not video-rate playback. Claude/Codex adapters, notification capture and video decoding are extension work, not included integrations.

Executables are unsigned; Windows may report an unknown publisher. All dependencies distributed in the archive retain their accompanying licenses. This is an independent community project, not an official JONSBO utility.
