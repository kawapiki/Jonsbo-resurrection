# Jonsbo Resurrection v0.6.1

## Install with one setup executable

Download **JonsboResurrection-0.6.1-Setup.exe**, run it, and click **Install**.
Setup installs the app for your Windows account, adds a Start menu shortcut and
an entry in Installed apps, then launches the controller. It includes the CLI,
AI helpers, documentation and dependency notices. No manual extraction is needed.

The stable install location is `%LOCALAPPDATA%\Programs\JonsboResurrection`.
Upgrades preserve layouts, display assignments, provider connections and startup
mode. Existing elevated startup requires same-account Windows approval to update.
Uninstall removes the application and its own startup registration while keeping
saved data in `%LOCALAPPDATA%\JonsboResurrection`.

A portable ZIP remains available for manual/portable use. Both downloads have
SHA-256 checksums. The application and installer are unsigned; Windows may show
an unknown-publisher or SmartScreen prompt.

Cyclops support and circular widgets from v0.6.0 are included. This release does
not install sensor drivers or change firmware. Startup can be enabled or disabled
from the app's tray menu after installation.
