# Jonsbo Resurrection v0.4.0

The local Display Studio brings visual layout editing to the JONSBO TF3-360SC on Windows amd64.

## Download and run

Download `JonsboResurrection-0.4.0-windows-amd64.zip`, extract the entire archive to a permanent folder, and run `JonsboResurrection.exe`. Choose **Open configurator** from the signature tray icon. The archive includes the console CLI, documentation and dependency licenses; the release also includes a SHA-256 checksum.

When upgrading, stop the previous controller before starting this version. If launch at sign-in is enabled, disable it in the old version and enable it again from the new version's tray menu so Windows uses the new executable.

## New in this release

- Display overview with connected pump/fan screens, serial numbers, status, current-output previews and live hardware readings.
- Visual editor with a clearly selected display, movable/resizable overlays, layer controls and draft-preserving navigation.
- Five editable themes: Arctic, Ember, Paper, Orchid and Terminal, sized for pump and fan displays.
- Live metric widgets, history graphs, usage rings/bars, text and disk usage/free-space readings.
- Local image backgrounds and bounded browser-imported video loops: up to 120 frames at 2 fps from the first 60 seconds, played by Go after import.
- Saved layouts, independent duplication, persistent display assignments and exact-render previews.
- Fan themes default to the verified horizontal installation's 90-degree rotation.
- README screenshots and configurator documentation.

## Requirements and known limits

Close the original JONSBO app before controlling the displays. Hardware support has been verified on one TF3-360SC installation. Ryzen CPU temperature requires the separately installed signed PawnIO driver and administrator access. Unsupported readings remain unavailable.

The four live hardware dashboards and real sensor readings were verified on physical hardware. The custom-layout editor, rendering, media imports and persistence were tested locally; applying custom layouts to physical screens has not been separately verified for this release. Automated CI cannot access USB hardware.

History is retained in memory for up to ten minutes. Video imports are low-frame-rate loops, not full-motion playback. Claude/Codex adapters and Windows notification capture remain future integrations. Executables are unsigned; Windows may show an unknown-publisher prompt.

This is an independent community project, not an official JONSBO utility. It changes display content, not cooling settings or firmware.
