# Jonsbo Resurrection v0.5.0

Readable AI activity widgets and a simpler Display Studio for the JONSBO TF3-360SC.

## Download and update

Download `JonsboResurrection-0.5.0-windows-amd64.zip`, extract the complete archive,
and run `JonsboResurrection.exe`. It includes the console CLI, native activity
observer, browser bridge/companion, documentation, screenshots and dependency
licenses. A separate SHA-256 checksum accompanies the ZIP.

Stop the old controller before starting the new copy. Keep
`%LOCALAPPDATA%\JonsboResurrection` to preserve saved layouts, display assignments
and monitoring preferences. If launch at sign-in is enabled, enable the same
startup mode from the new copy so Windows points to its executable. See the
[Windows update guide](https://github.com/kawapiki/Jonsbo-resurrection/blob/v0.5.0/docs/windows-app.md#updating-an-installed-copy).

## New features

- Native ChatGPT/Codex and Claude subscription monitoring reuses the official
  clients' existing sign-ins. Quota windows and reset times refresh in the
  background; token/context fields show only data supplied by supported feeds.
- Separate ChatGPT / Codex and Claude entries in the widget library, with
  connection status and sign-in guidance inside the selected widget's settings.
  The standalone AI connection page has been removed. Monitoring and optional
  session setup are available under **Connection & activity options**.
- Claude's square-eyed crab and the white ChatGPT blossom respond to running,
  waiting and idle activity. Animation frames are drawn in Go; no GIF/MP4 is
  played. The blossom's background is removed, including its open centre.
- Full-width fan cards use larger quota/token values and supporting text.
  Large token values are abbreviated; missing values stay `--`. Local and
  partial usage remain distinguishable from account totals.
- A clearer display workspace with readable controls, persistent save/apply
  actions, selected-display context and **On display / Edit layout** views.
- Optional native hooks, status-line and telemetry observations plus a paired
  browser companion for visible activity. Credentials and content stay local;
  the browser companion reports activity metadata, not tokens or exact context.

## Fixes

- CPU, GPU and memory fans open their own assigned output and matching editable
  starting layout instead of all showing the first fan's design.
- Late image responses cannot replace the selected display or a display card
  whose assignment has changed; cached images are invalidated with the assignment.
- Expanded 300-pixel AI widgets keep session context visible. Stale activity
  cannot animate a disconnected mascot, and sign-in-required status remains clear.
- Provider changes clear old sign-in guidance and discard delayed setup replies.

## Requirements and limits

Windows amd64 is supported. Close the original JONSBO application before driving
the displays. Ryzen CPU temperature requires the separately installed signed
PawnIO driver and administrator access. The app changes display content, not
cooling settings or firmware. Public executables remain unsigned.

AI subscription monitoring needs the official native Codex/Claude executable on
PATH and a subscription sign-in; shell wrappers and API-key sign-ins are not
supported for subscription quotas. Claude background quota monitoring requires
Code 2.1.293 or later and depends on its experimental native structured protocol.
No supported account-wide Claude token ledger is implemented. Local observations
are labelled partial. Unsupported or stale data is never presented as a fresh
account total. See the [AI guide](https://github.com/kawapiki/Jonsbo-resurrection/blob/v0.5.0/docs/ai-subscriptions.md) for exact coverage.

History is bounded and in memory. Imported background clips remain dashboard-rate
loops, with no audio or full-motion playback. CI uses fixtures without USB or
real account access. The installed redesign was exercised with existing layouts
and all four physical displays reporting live; this does not verify every
provider/client version or hardware installation.
