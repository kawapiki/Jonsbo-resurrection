# Jonsbo Resurrection v0.7.0

## Community contribution

Thank you to **[@dominikabrandhuber](https://github.com/dominikabrandhuber)** for
the animated Kuromi Cyclops theme, Thermal orbit widget and compact AI usage
improvements in [PR #8](https://github.com/kawapiki/Jonsbo-resurrection/pull/8).
All 15 original contribution commits and their authorship are preserved in the
project history. The contribution was integrated with shutdown and preview fixes
in [PR #9](https://github.com/kawapiki/Jonsbo-resurrection/pull/9).

## New display options

- **Thermal orbit** shows CPU temperature with large antialiased IBM Plex Sans
  numerals, a slashed zero and an animated light ring on Cyclops displays.
- The optional **Kuromi - Alive** theme adds blinking and winking expressions,
  gentle motion and a farewell animation on graceful exit. Its artwork, layout
  and import script are included in both downloads.
- Display refresh intervals can now be set as low as **125 ms (8 FPS)**.
  Hardware sensor sampling remains independent. Existing default and saved
  layouts are preserved; the new theme is opt-in.
- Compact AI provider strips now display available subscription usage: weekly
  quota, then five-hour quota or weekly tokens. Local/partial usage and
  unavailable, stale or expired states retain their qualifiers.

## Fixes

- Cyclops HID control and write waits now observe the farewell deadline and
  cancellation. Pending Windows I/O is cancelled and drained before buffers and
  handles are released. An unresponsive kernel driver can still delay cleanup.
- Requesting a farewell preview for a layout without a supported mascot returns
  HTTP **405** instead of an internal-server-error response.
- The Display Studio label now describes the small provider widget as a usage
  strip. Cyclops documentation also explains supported Ryzen temperature setup.

## Install or upgrade

Download **JonsboResurrection-0.7.0-Setup.exe** for the per-user Windows installer,
or **JonsboResurrection-0.7.0-windows-amd64.zip** for portable use. SHA-256 checksum
files accompany both downloads. Normal upgrades preserve saved layouts, display
assignments, provider connections and startup mode.

To import the optional theme while the updated controller is running, run
`./scripts/import-kuromi-theme.ps1 -Apply` from the installed application directory
or the extracted portable package. See the included
[theme guide](https://github.com/kawapiki/Jonsbo-resurrection/blob/v0.7.0/themes/kuromi-alive/README.md)
for device selection, animation settings and restoration instructions. Older
application versions cannot load layouts using the new widget or a 125 ms interval.

The application and installer are unsigned. This release does not install sensor
drivers or change firmware. Kuromi is a Sanrio character; the optional generated
fan art is not affiliated with or endorsed by Sanrio. IBM Plex font license and
artwork provenance notices are included.

## Verification and limits

The merged changes passed Windows tests, vet and builds with Go 1.24 and the
current stable Go version, portable Ubuntu checks, JavaScript tests, and the
isolated Windows install/upgrade/uninstall tests. Regression tests cover stalled
farewell transfers, native Windows event cancellation and unsupported previews.

The contributor reported physical Cyclops testing of live temperatures, idle
animation, graceful exit and saved-theme restoration. No additional physical
display, sensor, startup or shutdown testing was performed for this release;
full Windows shutdown remains unverified on hardware. Automated tests do not
access physical displays or install sensor drivers.
