# Signature artwork

`signature.png` and `signature.svg` are the maintainer's signature artwork reused from the Floating wheelcap project at the maintainer's request. Windows icon resources are generated directly from this existing PNG by the build script. The artwork identifies Jonsbo Resurrection; it does not imply endorsement by JONSBO.

`winres.json` declares the icon, an as-invoker manifest, and Windows version metadata. Building does not request administrator access. Elevated startup is a separate user choice.
